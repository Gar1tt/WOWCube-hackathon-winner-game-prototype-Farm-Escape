# 🐔 Farm Escape

**Farm Escape** is a survival game developed in **C++ for the WOWCube** during a university game-development hackathon.

The player must keep three chickens inside a farm while randomly breaking fences create escape routes. Players use the WOWCube's physical interactions to repair fences and survive for as long as possible.

🏆 **1st Place — University Game Development Hackathon WOWCube Challenge**

---

## 🎮 Gameplay

Three chickens move continuously across the WOWCube's connected screens.

The player must:

* Keep the chickens inside the farm.
* Repair fences before chickens escape.
* Survive as long as possible.
* Achieve the highest score possible.

As the game progresses:

* Fence break intervals become shorter.
* Chickens become faster.
* Multiple fences can break simultaneously.
* The difficulty continues increasing until all lives are lost.

The player starts with **5 lives**.

---

## 🕹️ Controls

| Interaction                     | Action                                                   |
| ------------------------------- | -------------------------------------------------------- |
| **Twist**                       | Repair all currently broken fences                       |
| **Pat**                         | Repair a broken fence associated with a chicken's screen |
| **Twist / Pat after Game Over** | Restart the game                                         |

A successful twist repair activates a short cooldown to prevent repeated use.

## 🧠 Game Systems

The game was implemented around several core systems:

### Chicken Movement

Each chicken has independent movement parameters and randomized wandering behavior. Chickens can move between the three connected screens and react to the boundaries of the farm.

### Dynamic Difficulty

The difficulty scales continuously during gameplay.

* Score increases every second.
* The round increases every 25 seconds.
* Fence break intervals decrease with each round.
* Multiple fence breaks become possible at higher rounds.
* Chicken movement speed increases as the player progresses.

### Fence System

Each fence has three states:

```text
SAFE → BROKEN → PATCHED
```

A chicken can escape when it reaches the bottom of a screen while that screen's fence is broken.

### Lives & Scoring

Escaping chickens reduce the player's lives. The game ends when all five lives are lost.

The final score is displayed on the Game Over screen.

### Rendering

The game renders independently across the WOWCube's three screens, allowing the farm to function as one connected environment.

## 🚀 Installation & Setup

### Requirements

* WOWCube SDK
* C++ development environment supported by the WOWCube SDK
* WOWCube device or compatible emulator/development environment

### Setup

1. Install the WOWCube SDK and its required development tools.
2. Clone this repository:

```bash
git clone <YOUR_REPOSITORY_URL>
cd FarmEscape
```

3. Open the project using the development environment configured for the WOWCube SDK.
4. Build the project.
5. Deploy the application to a WOWCube device or run it using a compatible emulator.

### WOWCube SDK Installation

If you are setting up the WOWCube SDK for the first time, this official WOWCube SDK documentation may help:

**[WOWCube SDK Installation Tutorial]([(https://wowcube.com/pdf/Quick%20Start%20Guide%20for%20WOWCube%20DevKit.pdf)])**

> Follow the official WOWCube SDK documentation for the current installation requirements.
